SQL Installation
---------------
Step 1: 
- Install SQL Server Express 2022
- https://www.microsoft.com/en-us/sql-server/sql-server-downloads?msockid=08fdf7830684630232e0e4d2072d62d6
- Refer to the link above. Then, scroll down and find Install SQL server Express 2022。
- Click 'Download' to install the SQL Server Express 2022

Step 2: 
- Run the SQL Server Express 2022 Installation and choose the basic type of installation
- Accept the term & condition
- Select the installation path and click 'Install'

Step 3: 
- After done the installation, click 'Install SSMS'
- Scroll down to 'STEP 2...', click 'Download SSMS 21'
- Run the Visual Studio installer 

Step 4: 
- After that, click 'Install' to install SQL Server Management Studio  21
- After done installation, click 'Launch' to launch the SQL Server Management Studio 21



SQL Configuration 
-----------------
Step 1: 
- Window search 'System Information' and run it 
- Under the 'System Summary', find 'System Name'

Step 2:
- Launch SQL Server Management Studio 21, type the system name that showed in the Step 1 in the server name column
- Add '\SQLEXPRESS' behind the system name. 
- For example, Server Name : MSI\SQLEXPRESS

Step 3: 
- At the Authentication column, choose 'Windows Authentication' and tick the 'Trust Server Certificate'
- After that, click 'connect'

Step 4: 
- Under the 'Object Explorer', double click the 'Security' and then double click 'Logins'
- Right click 'sa' and click 'Properties'

Step 5:
- Under the General page, tick 'Specify old password' and type the password '123456'
- Under the Status page, ensure the 'Login' is enabled 
- Click 'OK'

Requirement: 
- minimum of 4 GB RAM, recommend 16 GB RAM
- minimum of 4 GB up to 50 GB available Hard Disk Space
- .NET Framework 4.7.2 or above
